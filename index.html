V4.0.0WHY BILASCRIPT

01 Structure-first

AST giữ nesting và quan hệ cú pháp tốt hơn thay chuỗi/regex mù.

02 Evidence-driven Safety

Strict mode chỉ hạ alias khi có bằng chứng symbol/type phù hợp; thiếu evidence thì diagnostic.

03 Zero-cost JS Backend

Mapping 1:1 sinh JavaScript trực tiếp, không cần runtime translator riêng; tận dụng Web/Node/npm.

04 Offline & Tooling-ready

Core chạy offline; AST, diagnostics và Source Map tạo nền cho IDE/LSP và kiểm thử.

CÔNG DỤNG: học/nghiên cứu compiler, viết mã BilaScript hướng CVNSS4.0, biên dịch sang JavaScript và thử nghiệm tooling ngôn ngữ.
GIỚI HẠN: V4 không tuyên bố full ECMAScript/Test262; Python/C#/WASM/LSP/AI là hướng mở rộng nếu chưa nằm trong snapshot.

README.TXTDIRECT BROWSER MODE

F5 compile + run · F6 compile · F7 check · F8 AST · Ctrl+L clear output.

RUN dùng Web Worker và tự dừng sau 2000 ms để giảm nguy cơ vòng lặp vô hạn làm treo giao diện. Đây không phải security sandbox. Mã ESM có thể compile nhưng runner trực tiếp chỉ chạy script không có import/export.

Compiler trên trang được nhúng từ DevKit người dùng cung cấp; LAB-40 cũ chỉ dùng mini-runner giáo dục, còn Workbench này gọi trực tiếp lõi AST-first.
